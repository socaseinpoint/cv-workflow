# facts — the bedrock layer (core template)

> General anchors you can always stand behind. NO numbers, NO metrics, NO vacancy-specific wording.
> Details are derived later — by questions + research, for a specific application.

## <Company> · <period>
role: <what you were, in general>

### <Project>
- about: <domain/product, in general terms>
- did: <general verbs, true>
- stack: <named tools, no judgments>

## Style example (general vs hook)

### Acme · 2023–2024
role: full-stack

### AI assistant
- about: an LLM-powered helper product
- did: built a RAG pipeline, built the backend API, ran part of the frontend
- stack: TypeScript, Node, Postgres, pgvector, OpenAI

✅ like this — general, bedrock.
❌ NOT like this: "RAG precision@5 = 87%, p95 120ms, 50k-doc corpus" — that's a hook;
   people latch on and invent. Numbers come later, by question, per vacancy — only if you can back them.
